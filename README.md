### **Iteratione** — Online Code Execution Platform
*MVP Completed | [https://iteratione.com](https://iteratione.com)*

A proprietary platform for writing, testing, and executing code online with real-time feedback and multi-language support.

**Technical Challenges Solved:**
- **Security:** Containerized execution with Docker; untrusted code runs in isolated environments
- **Concurrency:** Job queue + worker pool architecture; 100+ concurrent submissions without blocking
- **Real-time Feedback:** WebSocket streaming of execution results to browser
- **Resource Management:** CPU/memory limits, timeout enforcement, automatic cleanup
- **Scalability:** Horizontal scaling via additional worker nodes

**Architecture Highlights:**
- Separate API layer (submission queueing) from execution layer (containerized workers)
- Redis job queue for decoupling submission from execution
- Docker containers with strict resource limits (CPU, memory, time)
- Worker pool pattern for concurrent execution
- WebSocket streaming for real-time result delivery

**Technical Stack:**
- **Frontend:** Tanstack Start, React, TypeScript, Tailwind CSS
- **Backend:** Fastify (Node.js), PostgreSQL, Redis
- **Infrastructure:** Docker, WebSockets, job queues
- **Tools:** Git, system design, performance optimization
